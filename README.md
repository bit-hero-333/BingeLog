# BingeLog

> **Disclosure:** This project was developed with heavy AI assistance ~~and is mainly public so I can benefit from GitHub's free Actions runners for automated APK builds.~~ No warranty, no tech support, use at your own risk.

Wanted a clean, local-first Android app to track movies, TV shows, and anime without needing to sign up for accounts, deal with bloated social feeds, or rely on external cloud services? Well, here is **BingeLog**.

You just install the APK, plug in a free [TMDB](https://www.themoviedb.org/) API key in Settings, and start tracking your watchlist right on your device.

### Features
- **Local-First Tracking**: Track Movies and TV Shows across *Watching*, *Plan to Watch*, *Completed*, *On Hold*, and *Dropped* with episode/season checklists, movie timestamps, rewatches, 1–10 scores, watch dates, and personal notes.
- **Discover & Upcoming Calendar**: Browse trending titles, filter by streaming service, actor, director, studio, or genre, and get local release notifications for upcoming episodes and movie premieres.
- **Stats & Achievements**: Customizable media insights dashboard and 70+ local achievements based on your watch history.
- **Full UI & Theme Customization**: System, Dark, Light, and true AMOLED Black modes, color presets, custom hex accents, and granular sizing controls for posters, text, and rows.
- **Offline Backups & Device Sync**: Automatic local safety backups, one-tap JSON backup save/restore via the system Files app, and direct device-to-device sync (6-digit PIN relay or offline QR).
